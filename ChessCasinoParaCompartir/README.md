# Chess Casino

Este juego es una web estática que se puede compartir tal cual.

## Cómo jugar

1. Copia toda la carpeta `chess` a otra persona.
2. Asegúrate de que incluye estos archivos:
   - `index.html`
   - `style.css`
   - `script.js`
   - `music.mp3`
   - `README.md`
   - `play.bat`
3. La persona puede abrir directamente `index.html` en su navegador favorito.

## Opción rápida en Windows

Si la persona usa Windows, puede hacer doble clic en `play.bat` para abrir el juego automáticamente.

## Si quieres una URL pública

Para convertirlo en una página web pública, sube esta carpeta a cualquier servicio de hosting estático como:

- GitHub Pages
- Netlify
- Vercel
- surge.sh

Con esto, cualquiera podrá ver y jugar sin instalar nada.
